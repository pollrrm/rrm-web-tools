Promo Scheduler

Show content only during a date/time window — no plugin. Paste what you want scheduled (e.g. a holiday-hours notice) and get a ready-to-paste block that shows and hides itself — or just grab a CSS class to put on an element you already have. Any site, any timezone.

Settings

Pick a timezone to pin the window to one clock everywhere (e.g. "ends midnight Pacific"), or Visitor's local time to run it in each viewer's own timezone.

Schedule window

Format: MM/DD/YYYY hh:mm:ss (24-hour; am/pm and seconds optional; date only = whole day). Keep the times at 00:00:00 → 23:59:59 for whole-day scheduling — just change the dates.

One-time snippet — paste once on the page

Paste once anywhere on the page — a site-wide header/footer code area, or any HTML / embed / code block. It controls every element that carries the class. The ready-to-paste block already includes this, so you don't need both.

How the scheduling works
  • Everything is hidden by default and shown only while “now” (in the chosen timezone) is inside its window — so nothing flashes before its time. For a holiday notice, set the End to the holiday and leave Start blank to show it from now until then.
  • It runs in the browser, so caching can't keep an expired item visible. Clear the cache once after publishing so the new content goes out.
  • You can schedule several items independently — each with its own window; overlapping windows show at the same time.
  • Dates are encoded in the class as <class>S<YYYYMMDDHHMMSS> / <class>E<…>; a date-only value counts the whole day (00:00:00–23:59:59).
