Promo Scheduler

Show or hide any element on any site during a date/time window — no plugin. Pick the window, copy the CSS class onto the element, and paste the one-time snippet once on the page. Works anywhere you can add a class to an element and drop a small snippet of code on the page.

Settings

Pick a timezone to pin the window to one clock everywhere (e.g. "ends midnight Pacific"), or Visitor's local time to run it in each viewer's own timezone.

How to install & how it works
  1. Paste the snippet once anywhere on the page — a site-wide header/footer code area, or any HTML / embed / code block. It controls every element that carries the class above.
  2. It hides those elements by default and reveals one only while "now" (in the chosen timezone) is inside that element's window. Because it runs in the browser, page caching can't keep an expired promo visible.
  3. Multiple elements each schedule independently — give each its own window. Overlapping windows show at the same time.
  4. Change the timezone or class name above and both boxes update — but if you already installed a snippet with a different class/timezone, replace it.
  5. After publishing, clear the site/page cache once.

Dates are encoded in the class as <class>S<YYYYMMDDHHMMSS> / <class>E<…>; a date-only value counts the whole day (00:00:00–23:59:59).
