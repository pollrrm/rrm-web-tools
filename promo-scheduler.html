Promo Scheduler

Show content only during a date window, or show a placeholder whenever nothing's running. No plugin; works on any site, in any timezone. Follow the steps and copy the code at the end.

Schedule window

Pick a start and end date on the calendar. Leave a date blank for an open end.

Click a field to open the calendar, or type the date. Leave a date blank for an open end: a blank start shows it from now, a blank end means it never comes down. Each promo runs the whole day unless you tick Set specific times.

Each page needs this engine once. If the page already runs an older promo engine, replace that old <script> with this one, since it runs your existing promos too. Pasting it twice is harmless; it won't double-run. (Option A's block already includes it, so you don't need this piece there.)
How the scheduling works
  • Everything is hidden by default and shown only while “now” (in the chosen timezone) is inside its window, so nothing flashes before its time.
  • It runs in the browser, so caching can't keep an expired item visible. Clear the cache once after publishing so the new content goes out.
  • You can schedule several promos independently, each with its own window; overlapping windows show at the same time.
  • Placeholder builds a fallback (same label + Else) that appears only when none of that label's promos are running, filling every gap, then stepping aside when the next promo goes live.
  • Dates are stored in the class as <label>S<YYYYMMDDHHMMSS> / <label>E<…>; a date-only value counts the whole day.
