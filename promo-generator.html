How to paste it into the homepage (WPBakery)
  1. Edit the homepage with WPBakery (backend or frontend editor).
  2. Add a Raw HTML element where the promo should sit (or open the existing promo's Raw HTML element to replace the old block).
  3. Delete anything inside it, paste the copied block, and Save Changes.
  4. Update the page. Done — it will appear/disappear on its own per the schedule. No need to come back to remove it.
  5. If the promo doesn't show up when it should, your caching may be serving an old page — clear the site/page cache once. (The show/hide logic itself runs in the browser, so cache never keeps a stale promo visible past its end date.)
