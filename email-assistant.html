Email Assistant

Draft, reply to, and polish email with Claude — from inside Gmail or Outlook Web via a bookmarklet, or right here by pasting. Thread context in, email body out. No preamble, no options to pick from.

1 · Setup no key saved

Stored in this browser only (localStorage on this site). The only place it is ever sent is api.anthropic.com.

Edit once; every mode uses it. Write rules, not examples.

Before using this on client mail: the thread text and your draft are sent to Anthropic's API to generate the reply. Use a dedicated API key with a spend limit, and keep anything under NDA out of it.

2 · Install the bookmarklet

Drag this to your bookmarks bar. Then open a Gmail or Outlook Web message, hit reply, and click it.

✉ Email Assistant
  1. Open the email you're replying to and click Reply, so the compose box exists.
  2. Optional: select any text on the page to use exactly that as the context instead of the auto-grab.
  3. Click the bookmarklet — this page opens in a tab with the thread and your draft already filled in.
  4. Generate, then hit Insert into email. The text lands in the compose box, above the quoted thread.
