Page Content Checker

A one-click bookmarklet that scans the live page you're viewing and flags likely content mistakes — placeholder text, broken/staging links, missing alt text, SEO structure issues, and dead conversion elements.

🔍 Check This Page

Drag this button up to your bookmarks bar. Then click it on any page you want to check.

How to use it

  1. Make sure your bookmarks bar is visible (Ctrl+Shift+B in Chrome/Edge).
  2. Drag the blue 🔍 Check This Page button above onto the bookmarks bar.
  3. Open any page you're working on — a live site, a WordPress preview, or a staging URL.
  4. Click the bookmark. A results panel slides in from the right listing every issue found.
  5. Click any issue to jump to it on the page (it flashes so you can spot it). Fix, then hit Re-scan.

Runs entirely in your browser on whatever page is open — nothing is sent anywhere. Works on logged-in WordPress previews and staging sites too, since it reads the page you're already viewing. It flags likely issues to review; it won't catch everything and may occasionally flag something intentional (e.g. a # link on a menu toggle), so use judgment.

What it checks

Content quality

  • Lorem ipsum / "your text here" placeholders
  • TODO / FIXME / TBD / XXX markers left in copy
  • Doubled words ("the the")
  • Mixed straight and curly quotes
  • Double spaces & space before punctuation

Links & media

  • Empty / placeholder links (#, javascript:void)
  • Links pointing at localhost / staging / dev domains
  • Images missing alt text
  • Broken images (failed to load)
  • Insecure http resources on an https page

SEO & structure

  • Missing or multiple H1s
  • Skipped heading levels (H2 → H4)
  • Empty headings
  • Missing / too-short / too-long page title
  • Missing or off-length meta description

Conversion elements

  • Empty or placeholder phone (tel:) links
  • Empty or example mailto: links
  • Placeholder numbers (555-555-5555)
  • CTA buttons with no destination
  • Forms with no submit action
