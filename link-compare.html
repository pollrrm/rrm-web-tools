Link Compare

Compare every link on two pages — your source vs the published WordPress post — to confirm each link made it across and points to the right place. Fetch a live URL or paste HTML/source on either side; reads real <a href> tags plus WPBakery/Elementor button shortcodes.

Source

What the page should link to — the original copy code or a live reference URL.

Published Page

The live post — what visitors actually get.

Advanced: custom fetch proxy (optional)

Free public CORS proxies are slow and unreliable — they often time out on large WordPress pages. For dependable Live URL fetching, deploy your own (a free Cloudflare Worker takes ~2 minutes) and paste its URL here. It's tried first, before the public fallbacks. Put {url} where the encoded target URL should go, or leave it as a plain prefix. Stored only in this browser.
